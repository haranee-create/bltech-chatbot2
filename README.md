# 뼈BTI 🦴 — 나는 어떤 뼈일까?

비엘테크 직원용 재미 + 제품교육 마이크로서비스.
**사진 한 장과 핵심 질문 7개**로 나의 **업무 유형(10가지)**을 알려주고, 그 유형을 닮은 뼈와
그 뼈를 지키는 **비엘테크 제품**을 소개합니다. 초상화는 그 뼈 옷을 입은 모습을
**그림판에서 마우스로 대충 그린 그림**으로 그려 금빛 액자에 걸어 줍니다.

흐름: 사진 → 질문 7개(한 장씩) → 소속(선택) → 업무 유형 · 성향 점수 → 닮은 뼈 + 초상화 → 우리 제품 → 공유

- **업무 유형 (`lib/roles.ts`):** 질문 7개의 각 선택지가 4가지 성향(지지·연결·돌파·섬세) 중 하나에 1점.
  1위가 2위보다 3점 이상 앞서면 순수 유형, 아니면 1·2위 성향을 짝지은 유형. 동점은 마지막 질문(나를 한 단어로)이 결정.
  같은 답이면 항상 같은 유형이 나옵니다.

  | 성향 조합 | 유형 | 닮은 뼈 |
  | --- | --- | --- |
  | 연결 + 돌파 | 리더형 | 슬개골 |
  | 돌파 + 섬세 | 전략가형 | 요골 |
  | 지지 + 돌파 | 실행가형 | 중족골 |
  | 지지 + 연결 | 조율자형 | 척골 |
  | 연결 + 섬세 | 기획자형 | 중수골 |
  | 지지 + 섬세 | 살림꾼형 | 거골 / 비골 |
  | 지지 | 버팀목형 | 경골 / 대퇴골 |
  | 연결 | 네트워커형 | 상완골 |
  | 돌파 | 해결사형 | 종골 |
  | 섬세 | 장인형 | 손가락 끝마디뼈 / 주상골 |

- **결과:** 업무 성향 미터 · 회사 속 역할 이야기(4문단, 소속을 고르면 그 부서 장면) · 강점 3가지 · 성장 포인트 →
  "왜 이 뼈일까?" 비유와 뼈 상식 → 그 뼈에게 필요한 우리 제품(사용법, 시술 영상은 버튼으로 펼침)
- **사진은 그림에만** 쓰고, 유형과 뼈는 질문 답으로만 정합니다 (얼굴로 사람을 판단하지 않음).
- 그림: `gpt-image-2.5-sunburst` (Image API `images.edit`) · 작문: `gpt-5.6-terra` (Responses API, JSON 스키마)
- **제품 도감(`/guide`):** 10가지 유형과 닮은 뼈 표, 부위별(팔·손 / 다리·발) 뼈 → 제품 → 시술 → 유튜브 영상.
- 공유: 세로 1200×1500(저장·카톡용), 가로 1200×630(페이스북 미리보기용) 카드 합성.
  페이스북은 게시글 문구를 미리 채울 수 없어서, 공유 버튼을 누르면 문구가 클립보드에 복사됩니다.

## 로컬 실행

```bash
npm install
```

`.env` 파일의 `OPENAI_API_KEY=` 뒤에 키를 넣고:

```bash
npm run dev
```

http://localhost:3000 접속.

## Vercel 배포

1. Vercel에서 이 GitHub 저장소(`haranee-create/bltech-chatbot2`)를 Import
2. **Settings → Environment Variables** 에 `OPENAI_API_KEY` 추가
3. **Storage → Create → Blob** 으로 Blob 저장소를 만들고 프로젝트에 연결
   (`BLOB_READ_WRITE_TOKEN` 이 자동으로 들어갑니다 — 페이스북 공유 링크용)
4. (선택) 커스텀 도메인을 쓰면 `NEXT_PUBLIC_SITE_URL` 에 주소를 넣기
5. Redeploy

> Blob 없이도 서비스는 동작합니다. 이 경우 페이스북 버튼은 공유 이미지를 내려받게 하고
> 사이트 주소만 공유합니다. (페이스북은 링크의 미리보기 이미지만 가져가기 때문에,
> 합성 이미지가 보이게 공유하려면 이미지를 공개 URL로 올려 둘 곳이 필요합니다.)

## 구조

| 파일 | 역할 |
| --- | --- |
| `lib/bones.ts` | **뼈 데이터 시트 · 제품(PRODUCTS) · 시술과 영상(PROCEDURES)** — 제품은 www.bl-tech.co.kr, 영상은 유튜브 @bltechco.ltd.2093 기준 |
| `components/ProductUse.tsx` | 제품 사용법 + 시술 설명 + 유튜브 영상(누르면 재생) |
| `app/guide` | 제품 도감 페이지 |
| `lib/openai.ts` | 작문(gpt-5.6-terra) / 그림(gpt-image-2.5-sunburst) 호출과 프롬프트 |
| `lib/roles.ts` | **질문 7개 · 성향 점수 · 업무 유형 10가지와 닮은 뼈 · 소속 부서 목록** |
| `components/TraitMeter.tsx` | 업무 성향 점수 미터 |
| `components/Shell.tsx` | 공통 레이아웃 (헤더 · 하단 고지) |
| `lib/ratelimit.ts` | 1인(IP)당 하루 생성 횟수 제한 |
| `app/api/generate` | 사진 + 답변 → 뼈 결정, 그림 + 결과 글 생성 API |
| `app/api/share` | 합성 카드를 Blob에 올리고 공유 링크 발급 |
| `app/s/[id]` | 공유 페이지 (페이스북 미리보기용 og:image 포함) |
| `lib/card.ts` | 공유 카드 합성(canvas), 업로드 전 사진 축소 |

## 비용 · 운영 주의

- 한 번 생성할 때마다 내 API 키로 그림 1장 + 글 1편 비용이 나갑니다.
  OpenAI 대시보드에서 사용 한도(Usage limit)를 꼭 걸어 두세요. 그림 품질은 `IMAGE_QUALITY`(기본 `medium`)로 조절합니다.
- `DAILY_LIMIT`(기본 5회)는 서버 메모리 기준이라 Vercel에서 인스턴스가 여러 개 뜨면 완벽하지 않습니다.
  엄격하게 막아야 하면 Vercel KV / Upstash Redis 같은 공용 저장소로 바꾸세요.
- 화면 하단 고지: "재미용 테스트이며 의료 진단이 아닙니다. 사진은 그림 생성에만 쓰이고 저장되지 않습니다."
